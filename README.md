# Rust 服务器管理工具

> Rust Solo Tools — 一站式 Rust 服务器管理工具，支持一键安装、联机配置、自动更新。

## 功能特性

- 一键安装服务器（本地直接部署，无需联网下载 SteamCMD）
- 联机功能（ZeroTier / 樱花 FRP / 局域网三种模式）
- 服务器 PVP / PVE 模式切换
- 指令大全快速查阅
- 自动检测工具更新，一键在线更新
- SteamCMD / Oxide / Carbon 插件框架管理
- 服务器备份与恢复

## 下载安装

### 方式一：直接下载

1. 前往 [Releases 页面](https://github.com/louxiaole/RustServerManager/releases)
2. 下载最新版本的 `Rust-Solo-Tools3.0.0beta.zip`
3. 解压到任意目录
4. 双击 `RustServerManager.exe` 运行

### 方式二：工具内自动更新

已安装旧版本的用户，打开工具后会自动检测新版本，点击「立即更新」即可在线更新。

## 使用说明

1. 首次运行后，在设置页面配置 SteamCMD 路径和服务器路径
2. 使用「一键安装」功能安装 Rust 服务端
3. 在「联机」页面选择联机模式（推荐 ZeroTier）
4. 在「服务器控制」页面启动/停止服务器
